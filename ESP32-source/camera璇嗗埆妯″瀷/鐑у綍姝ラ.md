## 硬件准备（必需）

### ESP32-CAM 连接电脑

ESP32-CAM **没有USB接口**，需要使用**USB转TTL模块**（常见型号：CP2102、CH340、FT232）来连接。

### 接线方式

**USB转TTL模块 ←→ ESP32-CAM**

```
USB转TTL      ESP32-CAM
--------      ----------
5V      →     5V
GND     →     GND
RX      →     TX
TX      →     RX
```

**重要：**
- RX和TX要交叉接（TTL的RX接ESP32的TX，TTL的TX接ESP32的RX）
- **烧录时**：用杜邦线将 **IO0 接 GND**（进入下载模式）
- **烧录完成后**：断开 IO0 和 GND 的连接，按ESP32上的重启按钮

### 你需要的硬件清单

1. ESP32-CAM 开发板
2. USB转TTL模块（CP2102或CH340）
3. 杜邦线若干（至少5根：5V、GND、RX、TX、IO0）
4. 电脑（Mac/Windows/Linux都可以）

## 5步完成初始图像采集

1. **硬件连接**：按上面的接线方式连接ESP32-CAM到电脑
2. **烧录固件**：在 Arduino IDE 烧录示例 CameraWebServer 到 ESP32-CAM
   - 打开 Arduino IDE → 文件 → 示例 → ESP32 → Camera → CameraWebServer
   - 选择开发板：AI Thinker ESP32-CAM
   - 修改代码：选择相机模型为 AI Thinker，填入你的WiFi SSID和密码
   - IO0接GND，点击上传
   - 上传完成后断开IO0，按重启按钮
3. **查看IP地址**：串口监视器 115200 查看设备 IP
4. **测试抓图**：先在浏览器打开 `http://你的IP/capture`，确认单张抓图可用
5. **批量采集**：
   ```bash
   # 进入工程目录
   cd /Users/yanyangnan/Desktop/camera识别模型/esp32cam_touch_bot

   # 给脚本执行权限
   chmod +x tools/capture_dataset.sh

   # 开始采集第一类（示例）
   ./tools/capture_dataset.sh -i 192.168.1.88 -l red_cube -n 300 -o dataset/raw -t 0.35
   ```

## 容易卡住的点（你现在最需要盯）

### 上传失败
先把 IO0 接 GND 进下载模式，烧录后再断开并重启

### 抓图失败
确认手机/电脑和 ESP32 在同一局域网

### 图片全糊
把抓图间隔从 0.35 提到 0.5 或 0.7，拍摄时慢慢移动物体

### 数据无效
每类必须覆盖 正放/侧放/斜放、远近变化、不同光照
