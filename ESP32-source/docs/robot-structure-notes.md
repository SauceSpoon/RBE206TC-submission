# 机器人结构档案

更新时间：2026-04-28

## 当前确认信息

- 机器人类型：双足机器人
- 腿部数量：2 条腿
- 总舵机数：6 个
- 每条腿 3 个舵机
- 每条腿自由度：3 自由度

## 单腿关节分配

每条腿的 3 个舵机分配如下：

- 膝关节：1 个舵机
- 髋关节：2 个舵机

其中髋关节的 2 个自由度为：

- 前后摆动自由度
- 左右摆动自由度

## 当前机械结构理解

基于 `odk2` 原始模型、`机器人样子/odk2.STEP` 和截图，当前对整机结构的理解如下：

- 这是一个双足、6 舵机的人形下肢结构
- 两侧腿根靠近机身的位置为髋关节双舵机结构
- 每条腿中下部有 1 个膝关节舵机
- 脚部为较大的落地支撑结构，目标偏向稳定站立
- 机身上方为电子平台/硬件仓

## 当前已识别的电子与硬件模块

在模型中已识别出以下模块：

- `ESP32`
- `PCA9685`
- `MPU6050`
- `XH-M401 Buck converter (XL4016E1)`
- `28BYJ-48 Step Motor`

## 当前系统架构理解

- 主控板：ESP32
- 舵机驱动：PCA9685
- 姿态传感器：MPU6050
- 电源模块：Buck 降压模块
- 机械主体：双足下肢 + 机身硬件仓
